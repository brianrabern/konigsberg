# KostochkaYanceyKernelLemma

## Book
`\label{KostochkaYanceyKernelLemma}`: If G is a superoriented graph with an
independent set I such that all edges in G−I have back arrows, then G is
kernel-perfect.

## Fidelity review
`HasBackArrows` on `univ \ I` encodes “all edges in G−I have back arrows”
(bidirected). Conclusion is `Superorientation.KernelPerfect`.
