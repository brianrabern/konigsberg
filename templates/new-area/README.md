# Areas/<NewArea>

Copy this directory to `formal/Konigsberg/Areas/<NewArea>/` to start a new area.
Adding an area should be MECHANICAL — if it isn't, the template is the bug.

Rules:
- Area-specific definitions live here, never in `Foundations/`.
- `Basic.lean` (definitions) is human-owned and reviewed before dependent work.
- Register the area root in `Konigsberg.lean`.
